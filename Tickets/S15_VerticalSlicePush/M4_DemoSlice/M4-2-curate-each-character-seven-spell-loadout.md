# M4-2: Curate Each Character Seven-Spell Loadout

**Goal:** Make each demo wizard’s default seven-spell loadout feel cohesive, expressive, and tactically complete.

## Tasks

### 1. Review Each Demo Spellbook
- Audit current spellbook assignments and extended spell lists for the chosen four wizards.
- Identify:
  - dead spells
  - redundant spells
  - unclear role overlap
  - matchup-warping outliers

### 2. Define Character Fantasy Per Wizard
- Summarize each demo character’s intended playstyle in one or two sentences.
- Use that summary to drive spell inclusion/exclusion decisions.

### 3. Curate For Match Quality
- Each seven-spell kit should support:
  - resource play
  - pressure
  - defense/counterplay
  - positional or tempo expression
- Remove novelty spells that do not improve actual duel quality.

### 4. Align Copy And Presentation
- Ensure loadout curation stays consistent with spell text, VFX readability, and AI behavior.

## Acceptance Criteria

- Each demo wizard has a curated seven-spell default loadout.
- The loadouts express distinct playstyles instead of feeling like loose piles of spells.
- Internal playtests do not reveal obvious dead picks in the curated kits.

## Dependencies

- Requires M4-1 roster locking.
