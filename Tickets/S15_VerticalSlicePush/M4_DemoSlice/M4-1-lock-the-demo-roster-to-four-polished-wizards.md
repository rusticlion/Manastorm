# M4-1: Lock The Demo Roster To Four Polished Wizards

**Goal:** Cut the playable/demo-facing roster down to four finished wizards so the vertical slice can be polished deeply instead of spread thinly.

## Tasks

### 1. Choose The Demo Four
- Select the four characters that currently offer the best mix of:
  - distinct mechanics
  - readable presentation
  - usable AI support
  - content completeness

### 2. Hide Unfinished Characters
- Remove unfinished or placeholder roster entries from the main demo-facing flow.
- Avoid exposing characters that reuse placeholder spellbooks or incomplete presentation.

### 3. Update Supporting Menus And Flows
- Ensure character select, attract mode, and any unlock/menu logic only surface the intended demo roster.

### 4. Document The Scope
- Record which four characters are in-scope for the demo and why.
- Treat additional characters as post-slice backlog unless they meet the same standard.

## Acceptance Criteria

- The demo-facing build only exposes four polished characters.
- No placeholder roster entries leak into character select or related flows.
- Content/polish work after this ticket is focused on the locked roster.

## Dependencies

- Should land before M3-5, M4-2, and M4-3 are finalized.
