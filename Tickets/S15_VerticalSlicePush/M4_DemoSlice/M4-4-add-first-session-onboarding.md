# M4-4: Add First-Session Onboarding

**Goal:** Teach a new player the core loop of Manastorm in the first few minutes without requiring external explanation.

## Tasks

### 1. Define The Minimum Lesson Set
- First-session onboarding should communicate:
  - shared mana economy
  - spell slot charging
  - range state
  - elevation state
  - basic blocking/counterplay expectations

### 2. Choose The Delivery Format
- Decide whether the slice needs:
  - lightweight tutorial prompts
  - contextual tips
  - a guided first match
  - or a combination of the above

### 3. Implement The Shortest Useful Version
- Prefer concise, well-timed onboarding over a long tutorial mode.
- Keep the teaching aligned with the actual playable demo loop.

### 4. Validate On Real New Players
- Watch at least a few fresh players go through the onboarding.
- Record where they still fail to understand the core loop.

## Acceptance Criteria

- A new player can understand the basic duel loop within the first session.
- Onboarding teaches the game’s actual rules and current UI language.
- The guidance is short enough not to feel like homework.

## Dependencies

- Should happen after M3-1 and M3-2 so the underlying communication layer is already improved.
